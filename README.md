## 📁 目录结构与规范

本仓库采用 **“主题/课程文件夹”** 形式组织内容。**所有新增资料必须存放在对应的文件夹内部，禁止直接在仓库根目录放置零散文件。**

```text
.
├── README.md
├── 01-计算机系统/                <-- 示例：按学科/主题划分的文件夹
│   ├── README.md                <-- 文件夹内部说明（可选）

│   └── code/                    <-- 示例代码/练习项目
